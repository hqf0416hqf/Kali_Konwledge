# C/C++ 与系统编程课程地图及接续

保持五个月阶段计划，使用 [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) 对照资源所有权、接口与并发，并按 [CS:APP](https://csapp.cs.cmu.edu/) 核对程序生命周期和系统 I/O。先修为基本控制流、函数、指针、引用及 C 编译运行。

## 覆盖状态

| 层次 | 单元 | 已知覆盖 |
| --- | --- | --- |
| 核心 | 类型、指针/引用/const、对象、作用域、生命周期、异常 | 用户自述学过构造/析构；其他语法和内存语义没有完整验收 |
| 核心 | 资源所有权、RAII、智能指针、拷贝与移动、规则三/五/零 | 2026-10-13 有 RAII 与 IntBuffer 讲授；移动语义在不同窗口有接触，无换题证据 |
| 核心 | 容器、迭代器、算法、模板、泛型接口 | 计划与接触材料存在；系统覆盖和独立实现未知 |
| 核心 | 编译/链接、CMake targets、错误处理、fd、进程、线程与同步 | CMake/Git 有笔记；open/read/errno 是待验证的系统编程连接点；并发覆盖未知 |
| 工程拓展与进阶 | gdb、ASan/UBSan、测试与性能分析；C++20、内存模型、低延迟并发 | gdb 和 sanitizer 有讲授或示例；无可核验的用户独立代码及输出，进阶未确认 |

## 学习证据与断点

- [CS-03、CS-13](学习状态.md) 保留 Git 与 C++ 的证据边界。Git 用户文字复述只支持局部理解；存在分支历史、CMake 等笔记并不能替代独立构建和调试。
- **接续**：从已有 IntBuffer 例子恢复，先解释资源由谁拥有、默认复制有何后果、删除拷贝操作后能否编译。让用户先作答并在 C++17 下实测，再进入移动构造、规则五/零及 sanitizer。另保留 fd/errno 的小实验用于 C++ 与 OS 接续。独立实现、并发及真实故障定位尚未验证。
