# Linux 课程地图与接续

沿用 [16 周融合框架](../../WIKI/CS/tools/Linux/Linux.md) 的项目与实验顺序。系统原理、硬件和网络分别见 [OS](操作系统.md)、[计组](计算机组成原理.md)、[计网](计算机网络.md)。前置为路径与进程的基本概念。

## 覆盖状态

| 层次 | 单元 | 已知覆盖 |
| --- | --- | --- |
| 核心 | 文件路径、重定向、权限、用户/组、Shell、环境与进程继承 | 路径、重定向、Shell、代理环境有案例；权限与 ACL 未见完整讲授 |
| 核心 | 包与服务、日志、存储、分区/挂载、文件系统管理 | df/lsblk、挂载和服务排错有讲授或观察；包管理、日志与服务管理的系统覆盖未知 |
| 核心 | 设备枚举、驱动匹配/绑定、模块、sysfs/procfs/dev、TTY、udev | 设备管理 01–05 已讲；详见 [CS-06 至 CS-08](学习状态.md) |
| 工程拓展 | strace、日志关联、受控复现、网络观测、性能指标 | 有既有排障案例；用户独立选择工具、解释输出、验证修复的完整链尚未验收 |
| 进阶 | eBPF、perf 火焰图、容器隔离、驱动源码 | 没有系统讲授证据；需要进程、I/O、测量及调试基础 |

基线见 [Linux 内核管理指南](https://docs.kernel.org/admin-guide/index.html) 与 [驱动绑定](https://docs.kernel.org/driver-api/driver-model/binding.html)。Linux 用户态工具与内核实现应分别核验。

## 学习证据与断点

- 能独立解释 Shell 内建 cd 的进程边界，能指出 USB 枚举不能证明驱动已绑定或通信成功。来源为仓库记录的书面复盘，见 CS-07；完整原答本次未复核。CH340/brltty 属提交过的现场日志，修复与重测未确认，见 CS-10。
- 用户原回答指出 TTY 子系统负责共性、具体驱动处理设备差异。当前对话可见历史片段，见“解释 DMA 与寄存器”回顾；只支持功能分层的解释，具体串口节点的绑定及权限排查待验。
- Linux 独立复习断点是用已有 USB 串口或历史日志区分枚举、驱动绑定和设备节点，先预测，再用 lsusb、sysfs 与只读日志核对。当前共享主课堂的前向进度在 [IPv4 与路由](计算机网络.md)，Linux 专题复习可从本段单独接续。
