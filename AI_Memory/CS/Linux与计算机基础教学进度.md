## 本窗口已讲与仍需巩固

- 设备管理：物理设备 → USB/PCIe 总线与枚举 → 设备模型与驱动匹配/绑定 → 内核功能接口 → 应用访问。区分模块文件存在、动态加载、驱动绑定、设备可用；理解 /sys 与 /dev 的不同职责。
- Shell/VFS：用户能解释 cd 必须影响当前 Shell、read 接口面向不同后端及页缓存；但未提交这两项的独立终端实验。
- CH340：用户提供 ch341 与 brltty 冲突的内核日志；能够识别“枚举成功不足以证明通信成功”；驱动解除绑定后的实际修复与重测未确认。
- 12 题阶段复习：用户独立文字作答显示 Shell/VFS/USB 证据边界较好；仍混淆 DDR/PCIe、模块文件与模块加载、readlink -f、Linux 网络接口；errno 最初属于教师尚未覆盖的前置知识。对应详见 CS-07 至 CS-09。
- STM32：F103 从片上 Flash 取指、预取缓冲区、SRAM 地址映射与 .text/.data/.bss 已讲，实际链接脚本/ELF 检验及用户复述尚未完成。与 Linux PC 的程序装载区别暂记后续计组重点。
- 网络：尚未获取用户实际运行 ip -br link、ip -br addr、ip route、ip route get 等命令的输出；既有 [网络故障排障长笔记](../../WIKI/CS/tools/Linux/Linux_CLI与网络故障排查_从零建立思路_含Codex案例.md) 是材料，不是掌握证据；正式 network 子目录目前只有占位文件。

## 下一节教学断点（先继续，不重启）

**网络模块 01：IP 地址、子网前缀、直接连接网络与路由。**

1. 从“Linux 如何决定发往某个 IPv4 目标的出口”引入；先区分网络接口、地址与路由，说明前置的二进制和位运算。
2. 用 192.168.1.105/24 逐位推导 255.255.255.0、网络前缀、直接可达的判断；不要只背“同网段”。
3. 与路由表中直连路由、默认路由比较，进一步引入 IPv4 ARP/邻居解析。将 IPv6 NDP 留在适当章节。
4. 讲解只读实验：ip -br link、ip -br addr、ip route、ip route get <目标>；要求用户先预测再查证。明确路由查询不等于数据包真正到达。
5. 用一个短题检查独立推理，再依据结果决定是否推进 ARP，避免一次覆盖 TCP、DNS、TLS。
6. 本单元结束记录是否真正运行命令、实际输出、错误原因、理解证据及下次起点。

## 待跨课程回补的关键断点

- 计组：DDR 内存通道与 PCIe/USB 控制器不是同一种接口；STM32 代码从 Flash 执行、Flash 预取与 PC Cache、启动向量/地址映射；I/O 控制器与 DMA 的真实数据路径。
- OS：文件描述符/打开文件对象/VFS、错误码 errno、系统调用与网络接口(Netlink/Socket)的差异；并发、虚拟内存、保护机制应按大纲逐项完成，而非因曾讨论就跳过。
- C++：在真实小程序中验证 open/read/write、perror/errno、fd 关闭与错误处理。
- RM 视觉项目独立记录见 [RM 自瞄项目进度](../Projects/RM视觉自瞄项目.md)，不可被基础课程进度覆盖。
