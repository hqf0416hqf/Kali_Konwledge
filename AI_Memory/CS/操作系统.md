# 操作系统课程地图与接续

沿用 [16 周融合框架](../../WIKI/CS/tools/Linux/Linux.md)，对照 [OSTEP](https://pages.cs.wisc.edu/~remzi/OSTEP/) 的虚拟化、并发和持久化。前置为 C 的指针与函数、计组的地址、特权和异常；Linux 具体版本和机制按文档核对。

## 学习证据与断点

- VFS 分派和页缓存命中有书面解释。用户能解释缓存命中可以直接从 RAM 获取文件内容，避开本次存储读取，并辨认内核与用户空间边界；不能由此推断能解释用户 buf、数据复制或所有 read 实现。来源见 [CS-07、CS-11](学习状态.md)。
- TLB 的翻译缓存与数据缓存的区别有用户陈述检索摘要，见 CS-11；未验证缺页处理和页表遍历的独立完整推导。
- **接续**：从 fd、打开文件对象、用户 buf 与内核页缓存的关系开始，用普通文件和 /proc 的对照区分语义。让用户独立预测 read 与 close 的行为，再写一个小程序用 strace 验证调用；strace 可观测系统调用，页缓存命中需要额外证据。
