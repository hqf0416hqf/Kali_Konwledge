## 学习证据与断点

- Cache 平均访问时间与映射的独立计算未验证。旧答题中出现 DDR/PCIe、Flash 执行与 SRAM 的混淆，教师已纠正，后续独立复述未核实。见 [CS-04、CS-08、CS-11](学习状态.md)。
- DMA 搬运与 CPU 配置的职责有口头复述线索；STM32 的总线仲裁、等待及其与 OS 阻塞的区别待验。见 [数字电路与嵌入式](../Hardware/数字电路与嵌入式.md)。
- **接续**：先画 DDR、PCIe/USB 控制器与 CPU 的拓扑；比较指令取自 Flash 与启动时初始化数据的路径，再用匹配芯片和工具链的 ELF/链接 map 对照。测量和换情境题均待执行。
