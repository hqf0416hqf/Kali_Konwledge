## 学习证据与断点

- 仓库书面复盘支持优先检查网卡驱动/接口层；未见真实 ip 输出或 /24 独立推导。历史代理/TLS 症状是局部现象；Clash 规则模式的根因、独立抓包与 MTU 实验未确认。见 [CS-09、CS-12](学习状态.md)。
- **接续**：网络模块 01。先区别接口、地址与路由；用 192.168.1.105/24 推导前缀和直连网络。让用户先判断两个目的地址分别走哪条路，再查看 ip -br link、ip -br addr、ip route、ip route get。区分路由选择与可达性；理解后再进入 ARP。命令边界见 [ip-route(8)](https://man7.org/linux/man-pages/man8/ip-route.8.html)。
