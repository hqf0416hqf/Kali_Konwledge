# 数字电路与 STM32：课程地图及接续

两个专题各有状态。数字电路参照 [MIT 6.004](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/)，STM32 参照 [ST 的 STM32F103 文档与 RM0008](https://www.st.com/en/microcontrollers-microprocessors/stm32f103/documentation.html)。仓库材料见 [Embedded 草稿](../../WIKI/Hardware/Embedded/Embedded.md)、[10-20 RAW](../../RAW/2026-10-20.md) 与 [10-22 RAW](../../RAW/2026-10-22.md)。

## 数字电路

- **核心地图**：二进制与逻辑代数 → 晶体管开关与逻辑门 → 组合逻辑（加法器、译码器、多路选择器）→ 时序逻辑（锁存、触发器、寄存器、计数器、有限状态机）→ 时钟及建立/保持时间。前置为基础电路、逻辑与位运算；工程拓展为消抖、同步器与时钟域，进阶为 HDL/FPGA。
- **覆盖和证据**：2026-10-20（北京时间）历史教师输出与 10-22 RAW 显示开关、门、组合/时序逻辑、寄存器与计数器已讲或接触。逻辑化简、状态机和时序未见系统覆盖，独立画电路/时序图尚未验证。
- **接续**：从半加器、全加器与触发器的区别入手，给一张小电路让用户画真值表或时序；能区分组合输出与状态后再回到 TIM 计数。

## STM32 与电路接口

- **核心地图**：电源/电平、GPIO/复用、存储映射与寄存器 → RCC/时钟与总线 → 定时器/中断/PWM、ADC → UART/I²C/SPI/CAN → DMA 与调试。工程拓展为 SWD、逻辑分析仪、驱动与编码器；进阶为闭环、RTOS、实时延迟。板级电路单列电源与负载、上拉、MOSFET/H 桥、续流与保护。
- **覆盖和证据**：10-12 的用户陈述检索摘要支持初步区分 GPIO、引脚和协议外设；10-29 的用户追问及教师复盘支持接触 CPU 配置、DMA 搬运的分工，独立解释程度仍需短题核验。AHB/APB、PSC/ARR/CCR、RTC、ADC 与 PWM 有讲授或材料；具体时钟、波形、UART/DMA 结果待验。
- **实践证据**：GPIO 与单电机试转有用户报告，范围与缺失日志见 [AutoQR](../Projects/AutoQR视觉小车.md)。它不验证 PWM 定时、DMA、UART 联调或电源稳定性。
- **接续**：给出实际时钟条件，让用户先推导 TIM 输入时钟、PSC/ARR 和预期周期，区分 CCR 和占空比，再量一条可重复的 GPIO/PWM 波形。DMA 另用一题区分外设接收、CPU 配置、DMA 搬运和软件处理；总线等待与 OS 线程阻塞分别建模。
