# 学习记忆导航

本系统以本地 Markdown 为权威数据源。阶段 1、2 已提供关键词检索、有限长度上下文组装、可审阅的记忆更新及恢复工具；用法见 [工具说明](tools/README.md)，结果见 [阶段验收](Projects/阶段1-2验收.md)。不同模型可人工接收同一组来源，跨入口自动加载、聊天同步及云服务尚未实现。

## 文件分工与读取顺序

1. [个人画像](../AI_Profile/Profile.md)：简短背景、稳定偏好和约束。
2. [当前教学断点](当前教学断点.md)：当前停在哪里、下次从哪里开始。
3. 按任务选读 [CS 学习状态](CS/学习状态.md) 或 [个人 AI 学习助手项目](Projects/个人AI学习助手.md)，再沿链接读取必要的 RAW/WIKI 正文。

RAW 保存素材，WIKI 保存正式知识，学习状态记录用户表现，项目记录保存执行结果。知识说明或 AI 执行成功均不直接证明用户掌握。详细事实只在所属文件维护，其他文件链接引用。新主题有实际记录时才新增文件，不预建空分类。

## 证据与状态约定

每项重要判断使用稳定条目 ID，并记录：判断、状态、来源类型与定位、证据日期、记录日期、确定程度、后续验证。日期不明就写未知，不把文件日期当作每段对话的精确发生日期。

| 状态 | 判定边界 |
| --- | --- |
| 接触过 | 用户自述或已有记录表明接触过主题，不推定能解释 |
| 能解释 | 有具体复述或解释内容；注明是直接观察还是用户转述 |
| 提示后应用 | 有任务、提示内容、用户操作或答案及结果 |
| 独立应用 | 有明确任务、用户独立产出及验证结果，并记录适用范围 |
| 尚未验证 | 缺少相应证据；可与“接触过”等并列，不表示不会 |

来源分为用户直接陈述、笔记已有内容、实际实验结果、AI 推测。实验须区分执行者是用户还是 AI；推测单独标注且不得升级能力。确定程度表示证据对当前判断的支持强度，不是熟练度分数。缺笔记、空目录、笔记错误都不能单独用来判定用户不懂。

本轮直接陈述来自当前任务消息，已在相关文件保存必要摘要或原句；原聊天没有仓库路径、行号或完整导出。2026-10-22 已读取用户指定的“规划个人AI助手”网页会话已加载正文，来源见 [CS-02](CS/学习状态.md)；其他入口完整历史未获取。RAW 属于二手整理，不能替代原始答题记录。引用仓库正文时保留相对路径、章节和核验时行号；文件修改后行号可能漂移，应重新定位。

## 更新、纠错与恢复

- 更新：先读现状，再只改对应条目，补日期、来源、结果与适用范围；新练习记录提示程度。教学结束后更新断点，不把计划写成已完成。
- 纠错：在原条目修正判断，附简短“日期／旧判断／更正原因／新证据”；来源冲突时保留分歧并标待确认，不自行选择较高能力等级。
- 撤回：标记条目“已撤回”，记录原因，停止作为当前事实使用，并修正引用处。
- 删除：按用户明确要求删除正文及相关引用；敏感内容不在变更说明中重复。删除工作区内容不等于清除 Git 历史或外部副本。
- 恢复：先用 `git log -- 路径`、`git show 提交:路径` 只读核对版本，再在用户授权范围内恢复指定文件并复核差异，避免整仓重置。未提交的新文件没有 Git 历史可恢复；本轮不提交、不推送，也未设置备份。

权限以当次任务为准。阶段 1、2 的代码、文档和恢复归档均存放在 `AI_Memory/`、`AI_Profile/`；WIKI 修改需当次授权。只存必要学习信息，不录入密钥或无关隐私。当前指南不授予后台持续运行、跨入口读取或付费操作权限。

## 程序维护约定

学习状态仍由证据驱动，工具不自动评级。日常修订可用 `update` 先预览后应用，提供当前哈希、来源、证据日期与修改原因；替换前保留本地恢复归档。旧事实应在原条目纠正或撤回，避免冲突条目一起进入上下文。具体命令及归档删除边界见 [工具说明](tools/README.md)。
