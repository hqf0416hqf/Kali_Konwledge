# 大学物理 B 课程地图与接续

课程以实际教材与作业要求为准；本轮核对的是公共覆盖基线 [OpenStax 大学物理第 1 卷](https://openstax.org/books/university-physics-volume-1/pages/10-introduction)、[第 2 卷](https://openstax.org/books/university-physics-volume-2/pages/1-introduction)、[第 3 卷](https://openstax.org/books/university-physics-volume-3/pages/1-introduction)。仓库 [力学笔记](../../WIKI/Physics/Mechanics/Mechanics.md) 很短，不能代替完整课纲。

## 覆盖与证据

- **力学核心**：运动学 → 牛顿定律 → 功能/冲量/动量 → 刚体转动、角动量与守恒 → 振动、波。前置为向量、叉积、积分。力矩与转动惯量已经讲授，碰撞与守恒有做题交流；振动、波及更前章节的系统验收未知。
- **其他本科范围待对照**：热学、电磁学、光学与近代物理的具体章节和范围待核本校大纲；本轮无讲授证据。工程拓展可连接转动、测量、传感器和相机光学。
- **PHY-01，2026-11-08**：可见的用户原回答说明半径平方关系使均匀杆不能拿中点替代全部质量；个人上下文还返回用户纠正了作业第 2 题的纸面内竖直 Oz 轴，并给出 7/3 md²。支持对转动惯量权重的局部解释及一道题的纠错线索；本轮未复看原题图和全套独立演算。平行轴与复合体的换题计算仍待验。
- **PHY-02，2026-11-09**：可见用户追问“不包括地球”和卫星单独/整体的守恒区别。碰撞解答的部分过程有二手回顾。需区分选取系统、参考点、外力/外力矩、作用时间和碰撞各阶段；尚未验证综合守恒判断。

## 下一次接续

保持“力矩与转动惯量”支线的慢速训练。先核题图和实际转轴，用一个复合体题检验选轴和积分/平行轴；再拿一个卫星或杆球碰撞题独立判断线动量与角动量的守恒条件。原作业第 3、4 题若可取得，优先接回原题。
