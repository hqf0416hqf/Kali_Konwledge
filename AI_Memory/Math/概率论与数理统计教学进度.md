# 概率论与数理统计：长期教学进度

## 课程定位与约定

- 本聊天窗口作为《概率论与数理统计》的长期主课堂，由 AI 组织系统教学；不是单纯的作业答疑。
- 课程目标：理解概率模型、随机变量与分布、联合/边缘/条件分布、独立性、数字特征、极限定理、数理统计的整体结构，能够独立识题、建模、推导、计算和检查；适时联系计算机视觉、传感器误差、卡尔曼滤波。
- 教学方法：数学动机与定义 → 直观例子 → 严格公式及其适用条件 → 推导 → 分层练习 → 用户独立作答与错因复盘。每节控制步长，先检查理解再深入；不把看过答案或提示后答对判为独立掌握。
- 这是与既有计算机基础和机器人视觉主线并行的数学课程，不替代其他学习目标。
- 正式 WIKI 默认只读；新增学习记录/状态依仓库 AGENTS.md 和 AI_Memory/README.md 的约定维护。此仓库为公开仓库，避免记录无关个人信息或敏感聊天内容。

## 课程知识地图（顺序可根据诊断微调，保持整体主线）

1. **概率语言与事件**：随机试验、样本空间、事件、集合运算、古典概型、条件概率、独立事件、全概率公式、贝叶斯公式。
2. **一维随机变量**：随机变量作为映射、分布律、分布函数、概率密度、离散与连续的联系、区间概率及常见一维分布。
3. **二维及多维随机变量**：联合分布函数/分布律/密度、取值支持集、边缘分布、条件分布、独立性、二维概率区域、随机变量函数分布。
4. **数字特征**：期望、方差、协方差、相关系数、条件期望、线性组合及相应定理。
5. **常见分布的综合应用**：伯努利、二项、泊松、几何、均匀、指数、正态；正态线性组合与独立性条件。
6. **极限定理**：大数定律、中心极限定理及其适用条件与近似。
7. **数理统计**：总体与样本、统计量、抽样分布、参数估计、置信区间、假设检验；视课程需要补相关和回归。
8. **工程联系与综合题**：测量噪声、不确定性传播、传感器融合/卡尔曼滤波中的概率思想。作为实践延伸，不代替基础证明与课程训练。

## 当前学习状态（截至 2026-11-11）

以下是当轮对话的观察和用户自述，不是正式测试结果或永久能力标签。

- **已接触，独立掌握待验证**：概率公理化、事件关系、随机变量定义、单变量分布律/密度/分布函数、常见分布、期望方差、协方差的直观意义。见 WIKI/Math/Probability-And-Statistics/Probability.md。
- **用户明确表示困惑**：读题时难以解释数学符号；从二维联合分布推出边缘分布、条件分布、独立性；二重积分上下限；正态变量线性组合的题型识别。仅能判断该类题目前需要支架，不据此推断所有基础薄弱。
- **练习暴露的潜在断点**：
  - (p_{ij}=P(X=i,Y=j)) 中符号到事件含义的转换。
  - (P(X_1X_2=0)=1) 与边缘分布对联合分布的约束。
  - 何时可用“常数密度×面积”、何时要积分。
  - 概率密度非零区域与目标事件区域的交集。
  - (f_Y(y)) 要保留 (y)，积分掉 (x)，且积分范围受支持集约束。
  - 正态 (N(\mu,\sigma^2)) 的第二参数是方差；线性组合中的期望和方差规则。
- **现有 WIKI 缺口**：二维联合、边缘、条件分布和随机变量独立性缺少完整体系；协方差公式尚未把 RAW 中“需要取期望”的纠正纳入正式 WIKI。只读，不擅自改 WIKI。

## 下一次课的教学断点

先以一个简单的离散随机试验确认“事件、随机变量取值、概率表达式”的互译；再使用同一张二维概率表推导联合 → 边缘 → 条件 → 独立，不先上积分。每次提一个短问题，等用户用自己的话解释并独立解一次，才继续下一概念。

重点检查：
1. 对 (P(X=1,Y=2))、(P(X=1))、(P(Y=2\mid X=1)) 能否说出样本范围的区别。
2. 是否理解边缘分布是在不限制另一变量时对其全部可能取值求和。
3. 是否能识别随机变量独立性是分布关系，不等于取值不同或不能相等。
4. 概念稳定后再过渡到连续型：积分、支持集及区域。
