# 线性代数课程地图与接续

沿用现有数学与视觉前置安排。仓库线代目录本轮只见占位；用 [MIT 18.06](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/) 补课程覆盖基线。

- **本科核心**：线性方程组/消元、矩阵运算与逆、行列式、秩、向量空间与子空间、线性无关/基/维数、线性映射与换基、正交投影、特征值/特征向量、对角化、二次型。前置为代数运算与向量几何。
- **工程拓展**：最小二乘、QR、SVD、齐次变换、协方差矩阵和正定性；先修为秩、子空间、正交与特征结构。进阶为数值条件与旋转群。
- **已接触和证据边界**：10-02 的历史用户计划把线代列入数学与项目基础；坐标变换在 [视觉材料](../../RAW/2026-10-12.md) 出现。未检索到有日期的线代独立推导/答题，具体章节停点与系统讲授覆盖未知。
- **接续诊断**：先给小矩阵让用户判断列向量能否张成整个空间、方程组有何种解，再让用户解释变换在做什么。根据答题找到旧课程实际停点；本诊断不会把已学内容归零。
