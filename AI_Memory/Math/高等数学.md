# 高等数学课程地图与接续

沿用 [高数笔记](../../WIKI/Math/Advanced‑Mathematics/Advanced‑Mathematics.md) 和原数学时段，参照 [MIT 18.01](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/) 与 [MIT 18.02](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/) 核对单变量、多变量覆盖；校内课纲尚未取得。

- **本科核心**：函数与极限、连续 → 微分与中值定理、Taylor → 定积分/反常积分与应用 → 数列/级数 → 多元极限、偏导/全微分、梯度与极值 → 重积分及坐标变换、线/面积分 → 常微分方程。先修为代数、三角函数与空间向量。
- **工程拓展与进阶**：Jacobian、线性化、最优化、傅里叶与拉普拉斯。与视觉最小二乘、概率支持集和控制建模连接；按需补齐前置。
- **已接触和证据边界**：[10-12 RAW](../../RAW/2026-10-12.md) 有偏导/全微分、Taylor、欧拉公式的教学和问题记录；傅里叶与微分方程仅见联系，拉普拉斯仅有兴趣线索。无独立推导或持续习题记录，近期正式章节未知。
- **接续诊断**：用一题区分偏导、沿指定方向变化和全微分；若正在为概率课补二重积分，先画支持集并解释积分界。依据真实答题决定复接点。
