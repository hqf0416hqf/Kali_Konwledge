# AutoQR Rover：视觉小车与最小电机验证

项目目标是从实际越线位置启动自主视觉，利用 RGB 相机寻找、识别、接近标签并停车。K210S/CanMV 负责视觉，STM32F103 负责下位机与模式/驱动；与 [RM 自瞄](RM视觉自瞄项目.md) 独立。先前 4WD 是已报告的早期硬件；2026-10-11 方案改用双编码器驱动轮与脚轮，实车是否按该方案完成未核实。

## 规则与方案版本

已核用户提供的校内赛 V1.4（2026-10-09，PDF 页 6、13–17、19，§1.2、§3.2、§3.3、§4.1）。两轮、每轮最多 180 秒，地形和视觉共用计时；20 cm 平台可选指定绕行，低矮通道、起伏构件仍须通过。视觉目标用 Tag36h11 ID 0，停车区中心距墙 725 mm；首次识别后持续使用 RGB，IMU/编码器可用于滤波、短时预测与速度控制。当前方案正文 v3 选绕行。早期 90 秒、丢标签固定秒数及目标距离的摘要不作当前规则；后续“要爬 20 cm”的讨论是否为新赛事约束或方案改变，未找到新版规则确认，单独保留待确认。

## 恢复入口

1. 台架复现单电机试转与停机，确认板型、实物使能、供电稳定与实际输入输出，保存可回查结果。
2. 再验证 K210→STM32 串口字节、解析结果、动作与超时停止。将控制逻辑与电源问题分开观察。
3. 并行以录制图像验收标签检测、标定尺度与 PnP；随后验收底盘低速、保护与停车。记录观测年龄、模式、命令、轮速、停止原因。台架试转不能替代视觉闭环验收。
