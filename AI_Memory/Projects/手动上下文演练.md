## 示范回答与证据边界

HEAD 表示当前检出的位置。通常通过当前分支间接指向提交；检出具体提交时，也可以直接指向该提交。

```text
通常：HEAD → main → commit C
分离：HEAD → commit B
```

因此，仅用“最新提交”描述 HEAD 不够准确：需要说明是哪条分支，以及 HEAD 是否处于分离状态。依据见上表 RAW 第 29–41 行。

已有记录说明你曾就这些概念提问，但不足以判断你现在是否还混淆。合适的后续观察是请你解释上面的关系，再核对只读命令输出。AI 完成这段示范不能升级 CS-02 或 CS-03。
