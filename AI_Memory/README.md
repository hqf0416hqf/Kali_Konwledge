# 学习记忆导航

## 新窗口如何接续

1. 确认实际可访问的仓库、默认分支和提交。读根目录 [维护规则](../AGENTS.md)、[设计草稿](../readme.md) 与 [长期系统教学规范](教学规范.md)。根目录草稿的占位与上传规划是历史描述，当前公开范围以远程实际树和本次授权为准。
2. 通过 [课程与项目断点索引](当前教学断点.md) 选择当前主题。只加载该主题文件，必要时读 [学习画像](../AI_Profile/Profile.md)、相关证据及 RAW/WIKI。课程入口同时列出覆盖、先修与本课程复接点；关联项目有独立状态。
3. 从该断点继续。用户有更新的明确进度时，先核验并补记来源。旧路线、其他课程断点、项目计划均不能覆盖所选课程的最新证据。

本地 Markdown 是学习工具的权威数据源。远程 GitHub 保存经授权的公开接续状态，入口按需实际读取；私密背景、完整聊天、本地未提交文件留在各自来源。手动读取可以跨窗口接续，跨入口自动加载、聊天同步、云服务尚未实现。工具见 [说明](tools/README.md) 和 [阶段验收](Projects/阶段1-2验收.md)。

## 文件分工与证据

- WIKI 保存正式知识正文，AI 默认只读；RAW 保存近期学习素材与观察。两者均不能单独证明独立掌握。AI_Profile 只存稳定的教学必要信息。
- AI_Memory 的主题页维护课程覆盖与教学断点，CS 证据账本维护具体表现，项目文件维护实际进展、验收和待办。历史恢复归档保留，不作为当前学习状态。其他入口用链接引用，避免重复结论。
- 每项重要判断给稳定条目 ID 或可定位小节，记录具体知识点、证据类型、证据日期或来源、提示程度、状态、确定程度和下一验证。日期不明时写未知，文件整理日与对话发生日分开。
- 可回查的用户作答、实验现象与产出优先。区分亲见原文、历史仓库记录、检索摘要、用户自述、教师讲授、推断和待确认。实验注明执行者与可取得的输出；报告过的试转与本轮实际复测分别描述。RAW/WIKI 引自同一记录时只计一次。排序、资料可信度与能力判断分别评估。
- 能力术语统一使用 [教学规范](教学规范.md) 的“接触过／能解释／提示后应用／独立应用／尚未验证”。接触或局部解释可与某项独立实操尚未验证并列。资料缺失不说明用户没学过。

## 首次全量校准与日常维护

- 2026-11-11 对仓库当前记录与可检索的个人学习上下文作了双向校准。原始历史不完整，带来源的旧记录继续保留。发现冲突时，最新明确用户决定与实际证据优先；无法确认时保留原范围和待核点。
- 日常更新只在有实质变化时进行。先读主题最新文件，增量记录新作答、实测、纠错、疑问或接续点。教学结束时记清已讲范围、实际表现和下一次起点；没有新证据就维持原能力评级。稳定偏好有变化才更新画像。
- 更正原条目时保留简短的日期、旧判断、理由和新证据；撤回的结论停止作为当前事实。按当次授权审查允许的路径、隐私和最新分支差异；提交后回读。禁止录入凭据或无关私密资料。
- 回查旧版先用 Git 历史或 [工具说明](tools/README.md) 的本地预览/恢复；在授权范围内恢复指定文件。删除工作区内容不能清除 Git 历史或外部副本。历史授权不会自动授予后续公开写入、后台运行或付费权限。

## 本地工具边界

本地工具提供字面检索、限定长度的上下文组装、可审阅的文本更新及归档恢复。更新可提供当前哈希、证据日期与原因。工具不会自动评定能力、合并并发冲突或判断证据真假。新课程接续优先用上方索引明确选材；程序的实际选材行为见 [工具说明](tools/README.md)。
