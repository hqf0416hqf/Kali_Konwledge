## 指令系统
###
- CISC (complex intruction set computer)
- RISC (reduced intruction set computer)
###

- 指令基本格式
```text
┌────────────┬──────────────┬──────────────┬──────────────┐
│   操作码    │   操作数1     │   操作数2     │   其他信息     |  
│  opcode    │   operand    │   operand    │              |
└────────────┴──────────────┴──────────────┴──────────────┘
```

- 分类
    - 根据操作数地址数量
        - 零地址指令 （例如:停机指令不需要操作数）
        - 一地址指令
        - 二地址指令
        - 三地址指令 (常见:1.操作数 2.被操作数 3.结果)  
        ...

- 指令助记符  
    - 指令助记符对应的不是一个固定机器码，而是由具体 ISA、操作数形式等共同决定具体的机器码编码。
    - 常用对应(以X86为例)
            MOV     ; 数据传送
            ADD     ; 加法
            SUB     ; 减法
            MUL     ; 乘法
            DIV     ; 除法

            CMP     ; 比较
            JMP     ; 无条件跳转
            JE      ; 相等时跳转
            JNE     ; 不相等时跳转

            PUSH    ; 入栈
            POP     ; 出栈
            CALL    ; 调用函数
            RET     ; 返回
