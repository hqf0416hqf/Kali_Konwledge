## 中央处理器（CPU）与指令系统
### 指令系统
- 参考链接  
  [计算机科学中最模棱两可的概念：指令集架构（ISA）与微架构深度解析](https://www.bilibili.com/video/BV16N336ZEjn/)  
- 指令集架构（ISA，Instruction Set Architecture）
  - 作用
    - 规定软件可以使用的机器接口。包括指令、程序可见的寄存器、寻址方式、地址空间、内存访问规则，以及异常与中断机制等。
  - 常见指令集设计特点（思想）
    - CISC（Complex Instruction Set Computer）：复杂指令集计算机，代表是 x86。
    - RISC（Reduced Instruction Set Computer）：精简指令集计算机，代表有 Arm、RISC-V。
    - （OISC（One Instruction Set Computer）：单指令集计算机）
- 指令基本格式
  ```t
  [ 操作码 opcode | 操作数相关字段（按需）| 其他信息（按需）]
    #操作码：执行什么操作，例如加法、传送、跳转。
    #操作数相关字段：可能指定寄存器、立即数或内存寻址信息，不一定直接存放操作数的值。
  ```
- 分类
  - 按显式地址数量分类
    - 零地址指令 
      - 解释
        - 不显式给出操作数地址 
      - 举例（示意）
        - 停机指令；栈式机器的加法可隐含使用栈顶操作数 
    - 一地址指令 
      - 解释
        - 显式给出一个地址，其余操作数或结果位置隐含 
      - 举例
        - 累加器式加法：`ACC ← ACC + M[A]` 
    - 二地址指令 
      - 解释
       - 显式给出两个地址，其中一个通常兼作结果地址 
      - 举例
        - `A ← A + B` 
    -  三地址指令 
      - 解释
        - 显式给出两个源地址和一个结果地址 
      - 举例
        - `C ← A + B` 
  - 备注
    - `ACC` 表示累加器，`M[A]` 表示地址 A 处的内存内容；箭头是操作示意，不是可直接运行的汇编代码。
    - 零地址不等于没有操作数，也可能使用隐含操作数。
    - *一条机器指令通常包含操作码，以及按需出现的操作数描述、寻址或控制信息。以上仅表示概念关系，具体字段与长度由 ISA 决定*
- 指令助记符
  - 意义
    - 历史从机器码进入汇编时代
  - 作用
    - 助记符是汇编中便于记忆的指令名称。
    - 同一个助记符不一定对应唯一的机器码，具体编码还取决于 ISA、操作数形式和位宽等。
  - 举例
    ```asm
      MOV     ; 数据传送
      ADD     ; 加法
      SUB     ; 减法
      MUL     ; 无符号乘法
      DIV     ; 无符号除法
      ; 比较与跳转
      CMP     ; 比较，更新标志位
      JMP     ; 无条件跳转
      JE      ; 相等时跳转（ZF = 1）
      JNE     ; 不相等时跳转（ZF = 0）
      ; 栈与过程调用
      PUSH    ; 入栈
      POP     ; 出栈
      CALL    ; 调用过程，保存返回地址
      RET     ; 从过程返回
    ```
  - 备注
    - *以下以 x86 为例，仅列名称与用途，不构成可运行程序*



## 存储系统
### 寄存器
- 常见寄存器
  - PC程序计数器 
    - 保存指令地址，用于确定取指位置
  - IR指令寄存器 
    - 保存当前正在译码或执行的指令
  - MAR存储器地址寄存器 
    - 保存本次访存的地址
  - MDR存储器数据寄存器 
    - 暂存从存储器读出的数据或准备写入的数据

*以下按教材中的简化 CPU 模型理解；实际处理器未必有同名、独立且程序可见的寄存器。*
