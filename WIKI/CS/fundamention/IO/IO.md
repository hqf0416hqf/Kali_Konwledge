- 执行文件的主要产生流程
  - 编辑源代码 （.c / .cpp）
    - 工具
      - 编辑器 
      - 举例:VS Code、Vim、nano
  - 预处理.i（C）/ .ii（C++）
    - 作用 
      - 处理头文件包含、宏展开和条件编译等
  - 编译：汇编代码 （.s）
    - 作用
      - 把预处理后的源代码转换为汇编代码
    - 工具:编译器
  - 汇编：目标文件 （.o）
    - 作用
      - 生成目标文件,*其中除机器码外，还可能有数据、符号和重定位信息*
    - 工具:汇编器
  - 链接：可执行文件  
    - 作用
        - 组合目标文件及所需库，解析符号引用并完成相应重定位
    - 工具:链接器
- 备注 
  *为了理解方便，以上的阶段划分以 GCC 工具链处理 C / C++ 为例*  
  *实际例如Python 的执行流程取决于解释器实现，不能直接套用这条 C / C++ 流程*
