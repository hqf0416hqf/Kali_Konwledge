# 摄影入门笔记

> 学习目标：理解相机、镜头和基础拍摄原理，能解释照片问题，并完成一组自然、清楚、风格一致的人像作品。
>
> 示例装备：索尼 A6400 + 适马 56mm F1.4 DC DN，索尼 E 卡口。

## 1. 摄影的基本框架

摄影是在一定时间内记录现场光线，并通过位置、构图、曝光和人物状态形成画面。

| 控制对象 | 具体内容 | 主要影响 |
| --- | --- | --- |
| 光线 | 方向、强弱、软硬、颜色 | 面部立体感、肤色、氛围 |
| 拍摄位置 | 距离、角度、高度 | 人物比例、透视、背景关系 |
| 画面范围 | 焦距、构图 | 特写、半身、全身、环境 |
| 记录方式 | 光圈、快门、ISO、对焦 | 明暗、景深、运动模糊、噪点 |
| 人物状态 | 表情、姿势、服装、动作 | 自然程度、表现力 |

**器材提供能力，拍摄者决定怎样运用。**

## 2. 机身与镜头

- **镜头**：收集光，在传感器上形成影像。
- **机身**：接收影像、控制曝光、运行对焦与处理算法、保存文件。
- **单机身**：通常不含镜头。
- **套机**：机身与一支或多支镜头的组合。
- **套头**：套机搭配的镜头，常见为入门变焦镜头。

| 部件 | 作用 |
| --- | --- |
| 透镜 | 使光聚焦成像 |
| 光圈 | 控制有效通光孔径 |
| 快门 | 控制曝光时间 |
| 图像传感器 | 将光转换为电信号 |
| 处理器 | 处理信号、运行相机功能 |
| 存储卡 | 保存照片和视频 |
| 屏幕、取景器 | 观察画面、参数和拍摄结果 |

## 3. 相机分类

不同分类描述不同属性，不要混用。

| 分类角度 | 类型 | 含义 |
| --- | --- | --- |
| 镜头能否拆换 | 固定镜头、可换镜头 | 是否允许换镜头 |
| 取景结构 | 单反、无反／微单 | 是否具有反光镜机构 |
| 传感器大小 | 全画幅、APS-C、M4/3等 | 传感器物理尺寸 |

- **单反**：有反光镜，通常使用光学取景器观察现场。
- **无反／微单**：没有反光镜机构，使用屏幕或电子取景器查看传感器画面。
- 微单可以是全画幅或 APS-C；单反也一样。
- 微单不一定小，单反不一定画质更好。
- A6400 是可换镜头、APS-C 画幅的无反相机。

## 4. 传感器与画幅

| 画幅 | 典型尺寸 | 常见特点 |
| --- | --- | --- |
| 全画幅 | 约36 × 24mm | 通常有利于弱光画质、浅景深；系统成本较高 |
| APS-C | 约24 × 16mm，品牌间不同 | 画质、体积和成本均衡 |
| M4/3 | 约17.3 × 13mm | 镜头系统容易做得较小 |
| 手机传感器 | 因机型而异 | 小型光学系统与计算摄影相结合 |

- 技术水平相近、拍摄条件可比时，大传感器通常有更多画质余量。
- 不能只看画幅判断所有相机的优劣。
- APS-C 足以学习人像，也能用于收费拍摄。
- “半画幅”是 APS-C 的通俗称呼，不代表照片质量只有一半。

## 5. 像素、清晰度与画质

一张6000 × 4000像素的图片约为2400万像素。

| 概念 | 主要由什么决定 |
| --- | --- |
| 像素数量 | 图片尺寸、裁切和输出余量 |
| 清晰程度 | 对焦、相机抖动、人物运动、镜头表现 |
| 画质 | 细节、噪点、色彩、明暗层次 |
| 审美质量 | 光线、构图、表情、内容 |

**高像素不保证清楚，也不保证好看。**

## 6. 镜头名称与接口

以“适马56mm F1.4 DC DN，索尼E卡口”为例：

| 名称 | 含义 |
| --- | --- |
| 适马／Sigma | 镜头品牌 |
| 56mm | 实际焦距 |
| F1.4 | 最大光圈 |
| DC | 适马相应小画幅镜头的标识 |
| DN | 适马为无反相机设计的镜头标识 |
| 索尼E卡口 | 连接机身的接口版本 |

- **卡口必须匹配**：同名镜头可能有多个卡口版本，不能直接互换。
- **原厂镜头**：通常指机身品牌自己的镜头。
- **副厂镜头**：其他品牌生产的兼容镜头，不等于假货或低质量。
- **自动对焦镜头**：相机可控制镜头对焦。
- **手动对焦镜头**：主要靠转动对焦环调整。
- **定焦镜头**：焦距固定，例如56mm。
- **变焦镜头**：焦距可调整，例如16–50mm。

## 7. 焦距与透视

### 7.1 焦距与视角

在同一台相机上：

- 焦距短：视角宽，装入更多场景。
- 焦距长：视角窄，局部或远处对象在画面中更大。

为了比较不同画幅，常使用全画幅等效焦距。

```text
等效焦距 = 实际焦距 × 画幅换算系数
索尼 APS-C：56mm × 1.5 = 84mm
```

**实际焦距仍是56mm，“等效84mm”描述视角。**

| 全画幅等效焦距 | 常见用途 |
| --- | --- |
| 16–24mm | 建筑、宽阔风景、夸张空间效果 |
| 28–35mm | 日常记录、环境人像 |
| 50mm左右 | 通用日常、人像 |
| 85mm左右 | 半身、人物特写 |
| 135mm及以上 | 远距离人像、舞台、运动 |

### 7.2 透视主要由位置决定

- 相机离脸太近，容易出现鼻子偏大、耳朵偏小的效果。
- 同样的人物构图，长焦通常需要站得更远，面部比例更容易自然。
- 固定拍摄位置，仅改变焦距，主要改变取景范围，不会改变场景的透视关系。
- 56mm在人像上好用，但小房间里容易退不开。

## 8. 光圈、景深与虚化

### 8.1 光圈

```text
F值 = 焦距 ÷ 有效孔径直径
```

- F值越小：光圈越大。
- F值越大：光圈越小。
- 完整一档序列：F1.4、F2、F2.8、F4、F5.6、F8、F11、F16。
- 每收小一档，进光量约减半。

| 调整 | 其他条件相同时的效果 |
| --- | --- |
| 开大光圈 | 进光多、景深浅、更容易虚化 |
| 收小光圈 | 进光少、景深深、前后更多区域清楚 |

### 8.2 景深与背景虚化

**景深**：照片中前后看起来足够清楚的范围，没有绝对清晰的边界。

影响因素包括光圈、焦距、对焦距离、画幅与最终观看条件。背景虚化还与人物到背景的距离密切相关。

想让背景柔和：

- 使用较大光圈。
- 在构图允许时靠近人物。
- 让人物远离背景。

注意：

- F1.4不必每张都用，近距离容易景深不足。
- 双人前后不在同一平面时，需要适当收小光圈。
- 虚化只是表达工具，环境人像也可以保留背景信息。
- 画幅换算不直接改变镜头的实际F值；等效景深不能当作曝光光圈使用。

## 9. 快门与模糊

快门速度表示曝光时间。

| 快门速度 | 常见效果 |
| --- | --- |
| 1/1000秒 | 更容易冻结较快运动 |
| 1/250秒 | 很多轻微动作人像的练习起点 |
| 1/60秒 | 人物移动时容易模糊 |
| 1秒 | 明显记录运动轨迹 |

两类常见模糊：

- **相机抖动**：相机在曝光时移动。
- **人物运动模糊**：人物在曝光时移动。

**防抖主要减轻相机抖动，不能冻结人物动作。**

使用56mm拍人，可从以下设置开始，再根据结果调整：

- 站立、轻微动作：1/250秒。
- 走路、明显动作：1/500秒。
- 快速运动：进一步提高快门速度。

## 10. ISO与曝光

### 10.1 ISO

- ISO是相机记录、处理和呈现曝光时使用的感光度设置。
- 低ISO通常有利于保留干净画质。
- 光线不足、快门和光圈受限时，提高ISO可以维持合适的输出亮度。
- 高ISO拍摄通常伴随噪点增加、明暗余量减少。
- 提高ISO不会给传感器增加光；噪点与实际收集到的光量密切相关。

**清楚的高ISO照片，通常比低ISO但人物模糊的照片更有用。**

### 10.2 三个参数的配合

| 参数 | 主要控制 | 取舍 |
| --- | --- | --- |
| 光圈 | 通光量、景深 | 大光圈容易景深不足 |
| 快门 | 曝光时间、运动表现 | 慢快门容易模糊 |
| ISO | 记录与输出亮度相关设置 | 高ISO下通常画质余量减少 |

人像思考顺序：

1. 想保留多少景深？选择光圈。
2. 人物怎样运动？选择快门。
3. 光线是否足够？调整ISO或改变拍摄光线。

### 10.3 曝光模式

| 模式 | 主要控制 |
| --- | --- |
| Auto，全自动 | 相机决定大部分设置 |
| A／Av，光圈优先 | 自己控制光圈 |
| S／Tv，快门优先 | 自己控制快门 |
| M，手动曝光 | 自己控制光圈和快门，ISO可手动或自动 |

- 入门可用A模式与自动ISO，但要检查快门是否太慢。
- 熟悉后可试M模式与自动ISO，同时固定光圈和快门。
- 曝光补偿用于告诉自动曝光系统把照片调亮或调暗；全手动且固定ISO时，补偿通常不会直接改变曝光设置。
- 自动模式可以用于正式拍摄，手动模式不是专业证明。

## 11. 对焦

对焦决定最清楚的焦平面在哪里。人像通常优先对眼睛。

| 模式 | 用途 |
| --- | --- |
| AF-S，单次自动对焦 | 相对静止的对象 |
| AF-C，连续自动对焦 | 人物或相机可能移动 |
| MF，手动对焦 | 自己调整对焦位置 |

常见对焦区域：

- 小点：明确指定位置。
- 区域：在局部范围寻找对象。
- 广域、追踪：相机识别或跟随对象。
- 人眼检测：优先寻找人物眼睛。

A6400人像练习起点：**AF-C + 人眼检测**。

拍完放大检查眼睛。人眼检测开启，不代表每张都会准确。

## 12. 光线

| 维度 | 观察内容 |
| --- | --- |
| 方向 | 正面、侧面、背后、头顶 |
| 软硬 | 阴影边缘柔和或锐利 |
| 明暗反差 | 脸部亮区与暗区的差异 |
| 颜色 | 日光、暖灯、彩色光是否混杂 |

- **柔光**：阴影边缘柔和，通常容易表现舒服的肤质。
- **硬光**：阴影明显，也可以形成有力量的效果。
- 光线软硬与光源相对人物的大小有关，不只是亮度强弱。

适合入门的场景：

- 窗边，人物稍转向窗户。
- 建筑阴影中，脸朝向开阔明亮处。
- 阴天户外，观察眼窝、下巴的阴影。
- 傍晚，尝试侧光与逆光。

练习：固定参数，让人物转动脸和身体，观察面部明暗变化。

## 13. 构图与人物引导

### 13.1 构图检查

- 背景是否有杂物或过亮区域。
- 树枝、柱子是否与头部重叠。
- 手脚是否被不舒服地截断。
- 人物是否是画面重点。
- 留白、线条、主体位置是否符合表达意图。

三分法、对称构图是工具，不是必须遵守的规则。

### 13.2 人物引导

少说“自然一点”，多给具体指令：

- 身体稍侧，脸转回来。
- 重心放在一条腿上。
- 慢慢走来，先看旁边，再看镜头。
- 轻轻整理头发、衣服，避免僵硬停住。

**帮助对方放松，是人像摄影的一部分。**

## 14. 白平衡、文件格式与后期

### 14.1 白平衡

- 用于处理光线颜色，使白色、肤色符合预期。
- 暖灯可能使画面偏黄，混合光源可能使不同区域颜色不一致。
- 白平衡准确不等于必须完全中性，也可以有意保留氛围。

### 14.2 RAW与JPEG

| 格式 | 特点 |
| --- | --- |
| JPEG | 相机已完成较多处理，文件较小、使用方便 |
| RAW | 保留更多原始记录信息，通常有更多后期调整余量 |

- RAW不自动更好看，需要适当处理。
- JPEG可以用于正式交付。
- 学习阶段可用RAW + JPEG，同时保留方便查看的版本和后期素材。
- RAW也不能无限挽救严重过曝、模糊或失焦。

### 14.3 基础后期流程

1. 选片：优先清晰、表情自然、构图合适。
2. 调整曝光、白平衡。
3. 调整明暗层次、色彩。
4. 修皮肤小瑕疵、背景杂物。
5. 统一整组风格。
6. 导出、交付并备份。

**肤色自然、整组一致，比只会套滤镜更重要。**

## 15. 摄影业务与收费能力

| 方向 | 主要能力 |
| --- | --- |
| 人像、写真 | 光线、审美、沟通、姿势引导、修图 |
| 婚礼、活动 | 抓拍、流程理解、应变、可靠交付 |
| 产品、电商 | 布光、材质表现、细节、批量一致性 |
| 建筑、空间 | 透视、构图、混合光线处理 |
| 运动、野生动物 | 时机、追踪、长焦使用 |
| 视频 | 声音、镜头运动、剪辑、叙事 |

校园人像业务流程：

1. 沟通需求、风格、时长、精修数量、交付日期。
2. 准备地点、服装建议、参考画面。
3. 拍摄与人物引导。
4. 选片、修图、统一风格。
5. 按约定交付和备份。

收费能力取决于稳定交付，不只取决于器材价格。

练习验收建议：给5位不同朋友各拍一组，每次都能交出约10张清楚、自然、风格一致的照片。此标准用于自测，不是行业统一规定。

## 16. 示例装备的适用范围

**索尼A6400 + 适马56mm F1.4，索尼E卡口。**

| 任务 | 适用程度 |
| --- | --- |
| 校园、公园单人半身与特写 | 很适合 |
| 户外全身人像 | 适合，需要拉开距离 |
| 少人数合照 | 可拍，需要空间和足够景深 |
| 小房间全身人像 | 容易退不开 |
| 毕业大合照、活动全景 | 单靠56mm不方便 |
| 重要活动全程记录 | 需要考虑镜头覆盖与备用器材 |

- 先用熟这套装备，再根据实际限制补镜头。
- 大光圈不能替代好光线、干净背景和自然表情。
- 机身升级不能直接解决构图、沟通与后期问题。

## 17. 学习与练习顺序

| 阶段 | 学习重点 | 练习任务 |
| --- | --- | --- |
| 1. 拍清楚 | 对焦、快门、曝光 | 拍站立和走动的人，检查眼睛与运动模糊 |
| 2. 控制虚化 | 光圈、距离、背景关系 | 固定构图比较F1.4、F2.8、F5.6 |
| 3. 看懂光线 | 方向、软硬、明暗反差 | 窗边转动人物，观察面部阴影 |
| 4. 拍得自然 | 构图、姿势、沟通 | 完成特写、半身、全身照片 |
| 5. 完成作品 | 选片、后期、统一色调 | 交付一组约10张照片 |

### 拍摄前检查

- [ ] 电池充足，存储卡空间足够。
- [ ] 镜头卡口正确，镜片无明显污渍。
- [ ] 文件格式、对焦模式已设置。
- [ ] 快门足以应对人物动作。
- [ ] 光圈提供足够景深。
- [ ] 背景、面部光线和白平衡已检查。

### 拍摄后检查

- [ ] 放大查看眼睛是否清楚。
- [ ] 人物是否运动模糊。
- [ ] 肤色与曝光是否合理。
- [ ] 表情、姿势、背景是否合适。
- [ ] 文件已备份。

## 18. 常见误区

| 误区 | 正确认识 |
| --- | --- |
| 全画幅才能接单 | APS-C也能完成高质量人像，关键是稳定交付 |
| 像素高就清楚 | 对焦、快门、抖动同样关键 |
| F1.4必须一直使用 | 景深不足时应收小光圈 |
| ISO越低越好 | 先保证快门与清晰度，再兼顾画质 |
| 防抖能冻结人物动作 | 防抖主要减轻相机抖动 |
| 长焦本身改变脸部透视 | 主要是拍摄距离变化造成 |
| RAW能救所有问题 | 严重模糊、失焦、过曝无法无限恢复 |
| 手动模式才专业 | 合理选择模式、稳定取得结果更重要 |
| 买好相机就拍得好 | 还要练光线、构图、引导、后期 |
