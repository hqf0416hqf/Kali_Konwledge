假设目标在平面中的位置是 `(x, y)`，它到原点的距离为：

```
r(x, y) = sqrt(x² + y²)
```

位置测量有一点误差，距离会受多大影响？这需要恢复的就是**偏导和全微分**。

在位置 `(3, 4)`：

```
r = 5

对 x 的偏导 = x / sqrt(x² + y²) = 3/5 = 0.6
对 y 的偏导 = y / sqrt(x² + y²) = 4/5 = 0.8
```

两个偏导分别描述：固定另一项时，该输入的小变化会怎样影响距离。把两项影响合起来，得到一阶近似：

```
距离改变量 Δr ≈ 0.6 × Δx + 0.8 × Δy
```
推导
```
(r + Δr)² = (x + Δx)² + (y + Δy)²  
  
r² + 2rΔr + (Δr)²
    = x² + 2xΔx + (Δx)²
    + y² + 2yΔy + (Δy)²

**关键就在这里：当位置变化相对于距离足够小时，平方项是更高阶的小量。** 一阶近似只保留变化量的一次项

Δr ≈ (x/r) × Δx + (y/r) × Δy

相当于:Δr ≈ x的偏导×Δx + y的偏导×Δy
```

---

| 系数 | 数学含义 | 工程含义 |
|---|---|---|
| `∂r/∂x = x/r` | 固定 y，r 对 x 的变化率 | x 的小变化对距离有多敏感 |
| `∂r/∂y = y/r` | 固定 x，r 对 y 的变化率 | y 的小变化对距离有多敏感 |

**全微分把这种关系推广到了其他可微函数：**

```
对于 z = f(x, y)：

dz = (∂f/∂x) dx + (∂f/∂y) dy

于是Δz ≈ (∂f/∂x) Δx + (∂f/∂y) Δy


- `Δz` 是函数值的**实际变化**。
- `dz` 是由偏导构成的**线性预测**。
- 函数可微时，变化足够小，二者的差比输入变化本身更高阶。
微分方程本身也可以是非线性的；求解时采用哪一种近似，是另外一层选择。

```
