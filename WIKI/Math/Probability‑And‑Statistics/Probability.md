## 概率
### 概率论的形成与公理化
- 基本模型
    - （a解释）.古典
        - 定义
            - 有限个样本点
            - 每个样本点等概率
        - 公式
            有利样本点个数/样本点总个数（样本空间）
            - 举例
                抛硬币样本空间含正面、反面两个等概率样本点，因此正面朝上概率为1/2；
                掷骰子样本空间有1-6六个等概率样本点，偶数为2、4、6共三个，偶数概率3/6=1/2
    - （b解释）.频率
    - 公理化
        - 定义
            - 非负性：P(A) ≥ 0
            - 规范性：P(Ω) = 1
            - 可加性：A、B 互斥时，P(A∪B) = P(A) + P(B)
        - 意义
                把概率从"玄学"变成严格的数学——一切结论都能证明。这也是后面整个数理统计和统计推断可信的根基
- 思考  
&nbsp;&nbsp;&nbsp;&nbsp;古典概率、频率概率、概率的公理化是三种理解/建立概率理论的思路  
&nbsp;&nbsp;&nbsp;&nbsp;古典概率适用于基本结果有限且等可能的随机试验  
&nbsp;&nbsp;&nbsp;&nbsp;频率解释以可重复试验为典型背景，用长期相对频率来刻画概率   
&nbsp;&nbsp;&nbsp;&nbsp;二者都有较大的局限性  
&nbsp;&nbsp;&nbsp;&nbsp;于是公理化出现了，不在试图给“概率”下一个唯一的直观定义，而是规定一个概率测度必须满足哪些公理  
&nbsp;&nbsp;&nbsp;&nbsp;最终的公理化方法成为现代概率论的数学基础。  
&nbsp;&nbsp;&nbsp;&nbsp;（古典、频率、贝叶斯主要是在讨论“概率如何解释”；公理化是在讨论“概率如何被严格数学化”）

### 概率的性质
    • P(∅) = 0，P(Ā) = 1 − P(A)
    • 有界性：对任何事件 A，0 ≤ P(A) ≤ 1
    • 单调性：若 A ⊆ B，则 P(A) ≤ P(B)（B 至少包含 A 的全部结果，概率当然不小于）
    • 加法公式：P(A∪B) = P(A) + P(B) − P(A∩B)
② 古典概型：P(A) = A 的等可能结果数 ÷ 总等可能结果数。大学的全部工作就是"怎么把数数数得又快又对"——排列组合那一套﻿
③ 事件的关系与运算 + 德摩根律：交、并、补、差、包含、互斥、对立。唯一值得记住的是德摩根律（对偶律）：#P(A∪B) = P(A) + P(B)-P(A∩B)﻿
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ﻿
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ﻿


### 概率的公式
- 条件概率
记 P(A | B) 为"已知 B 发生的条件下，A 发生的概率"
P(A | B) = P(A ∩ B) / P(B)（要求P(B) > 0）
（等价变形）乘法公式（把除法倒过来，后面会反复用）：P(A ∩ B) = P(B) · P(A | B)

## 随机变量
### 随机变量
- 定义(事件数值化)  
                设 Ω 是样本空间。随机变量 X 是从 Ω 到实数集 ℝ 的一个函数,  
                每个样本点 ω（一次试验结果）对应一个实数 X(ω)。  
- 作用（存在原因）:我们关心的往往不是"具体哪个结果"，而是结果带来的数。随机变量就是把每个结果映射成一个数的规则。
- 举例 X(正正)=2，X(正反)=1，X(反正)=1，X(反反)=0
- 备注ps：
    - X 是一个函数，不是一个数字本身；
    - X 的随机性 = Ω 的随机性（来源同一）
（硬币为例子翻译成人话就是: 随机性在 Ω（硬币那里），X 只是被结果牵着走的"翻译器"。X 自己没有随机性，它的不确定 100% 是从 Ω 借来的。）
- （承上启下）和分布的关系: 多个结果可以映射到同一个数字（X=1 有两个来源）→ 这就是下一层"分布"的种子。

### 随机变量的研究
- 分布律P(x)
  - 运用范围
    - 离散型随机变量
  - 判断（判断是不是合法分布律）
    - 非负性​
    - 归一性：全部概率加起来总和等于 1
  - 表示
    - 表格形式（取值+概率）
    - 函数表达式
- 概率密度函数f（x）
  - 运用范围
    - 连续型随机变量
  - 判断
    - 面积1（对应归一性）
- 分布函数F(x)
    - 定义:分布函数离散、连续通吃。因为它只问"不超过 x"，而 x 可以是任意实数。x是一直变多的（直到到达1）
    - 举例  
    P(X=1)=0.2,P(X=2)=0.8..  
    求P(X=1.5)和F(X=1.5)
    答案是0和0.2  
  ##f（x）密度
  分布函数的斜率就是'密度'。
  ##思考
  我记得之前刷视频的时候，有博主讲过，一个违反直觉的悖论。一条连续发生的事件。比如等车，6分钟一趟，等待时间（即事件的取值）是0-6的任何一个点。P（x）（x属于0-6）的值永远是0
  又想到另一个比喻：（质量＝体积*密度）
  ▎ 把 [0,6] 想成一根长 6 米的细杆，总重量 1（= 概率）。
  ▎ 杆上单独一个点有重量吗？没有——点没有厚度。
  ▎ 但整根杆重 1。矛盾吗？不矛盾。因为你从来不是"把点的重量加起来"，而是把密度沿杆积分（每米的密度 × 长度）。
  ▎ 连续概率走的正是这条路：不靠"点的概率相加"（那是离散），靠"密度积分"（这是连续）。

### 随机变量的分布
- 离散型
  - 伯努利分布(X ~ B(1,p))
    - 一次试验，结果只有 0/1
  - 二项分布 (X ~ B(n,p))
    - n 次伯努利
  - 泊松分布 (X ~ Pois(λ))
    - λ：平均单位时间发生次数
    - 应用场景:‘某事件’平均每单位时间发生 λ 次，在某一单位时间里‘某事件’恰好发生 k 次的概率。
    - 公式: P(X=k) = λ^k e^(-λ) / k!
- 连续型
- 指数分布(X ~ Exp(λ))
  - 描述事件之间的等待时间
  - f(x) = λe^(-λx)
  - E(X) = 1/λ
  - 特点：无记忆性
  - 泊松数次数，指数数间隔
- 均匀分布
  - 区间内各位置等可能(X ~ U(a,b))
  - f(x) = 1/(b-a)
- 正态分布(X ~ N(μ,σ²))
  - 数据中间密、两边稀
  - μ：均值，决定位置
  - σ：标准差，决定分散程度
  - σ 越小，数据越集中
  - 应用：测量误差、传感器噪声

  、、、、、、、、、、、、、、、、、、、、、、、、、、、、、

  ###公式
  P(X=k) = λᵏ · e^(−λ) / k!
  ##指数分布（无记忆!）
  如果泊松数"件数"，指数就数"间隔"——等到下一次事件要等多久。
  密度 f(x) = λ·e^(−λx)，均值 = 1/λ
  平均每 20 分钟抛锚一辆（λ=1/20）→ 从一辆到下一辆，平均等 1/λ = 20 分钟
  ##均匀 U(a,b)：等车那个，f=1/(b−a)，每点等可能。
  ##正态 X~N(μ, σ2)
  ###公式
  ▎ f(x) = ( 1 / (σ·√(2π)) ) · exp( −(x−μ)2 / (2σ2) )
  ###相关概念
  正态分布 N(μ,σ2)：μ=位置（对称轴），σ=胖瘦；
  ps：σ越小，正态分布图就越尖，工程上，噪音取到较小取值的可能性就越大。
  ###应用
  工程项目的噪音。
  ###举例
  你的测距传感器测目标距离，真值是 23.47 cm。测得有误差：多数时候 ±0.1 cm，偶尔 ±0.5，极偶尔离谱偏出 2 cm。
  //思考： 这些误差是"均匀分布"的吗？ 还是说——落在真值附近（±0.1）的次数多，还是偏得老远的次数多？
  //答：真实世界的误差 / 噪声，是"中间密、两边稀"的，符合正态分布。

##协方差
###应用
（解释：我们已经有两个工具：期望（描述 X 自己平均在哪）、方差（描述 X 自己有多散）。但它们都只描述一个变量自己。可现实里我们常常同时面对两个变量，而且想知道它们之间的关系）
（协方差要回答的问题：两个变量是"同向"、"反向"、还是"没关系"？ 而且要用一个数字回答。）
例如：
- 自瞄：目标的位置位移 X 和 速度 Y——目标动得猛的那几帧，位移大，速度是不是也大？
- 身高 X 和体重 Y：高的人一般更重（同向）
- 学习时间 X 和成绩 Y：同向；温度 X 和羽绒服销量 Y：反向
###公式
（X-X的均值）*（Y-Y的均值）
（核心思想一句话：看 X 偏离自己均值时，Y 是不是往同一方向偏离。）
- 同向：X 比均值高时，Y 也比均值高 → 加分（+）
- 反向：X 比均值高时，Y 反而比均值低 → 扣分（−）
- 无关：时正时负，加加减减抵消 → 接近 0
