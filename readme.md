## 设计草稿
RAW （ai权限6可读可改）ai维护,写给人类看的。内容为网页/终端cli/应用等gpt能获取的所有信息来源，整理近期学习的新技术、概念名词等我新接触技术，作为WIKI素材草稿库。
WIKI （ai权限2可读不可更改）主要人工维护。是个人长期维护的笔记ai只读，当且仅当在用户同意后，可以辅助整理指定文件
AI_Memory （ai权限可6读可改）ai维护全自动仓库。ai根据人制作的个人知识库WiKI，和日常聊天（网页/终端）等各种你了解我的渠道，自动维护这个仓库，以便于ai好的了解我。目前设计中，知识库是分层。比如数学/CS/英语（当然下面还会细分）等等，ai根据当前聊天内容选择具体细度的部分模块。。AI_Memory 应记录“用户与知识的关系，用户对知识的掌握判断，不要变成的WIKI复制品。注意AI 记忆都需要区分事实与推测。
AI_Profile （ai权限可6读可改）用户个人画像，用作每一轮聊天上下文的常用记忆。AI_Profile 要短，而且不能变成永久标签。其实这个功能和大模型缓存的memory有点重复的，但是为了方便不用模型切换，决定保留此功能。
